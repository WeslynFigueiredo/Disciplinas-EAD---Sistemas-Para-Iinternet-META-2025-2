💬 O que é SQL? - A Linguagem do Banco de Dados

Definição
SQL (Structured Query Language) é a linguagem padrão para gerenciar e manipular Bancos de Dados Relacionais. É universalmente aceita e usada em praticamente todos os SGBDs (MySQL, PostgreSQL, Oracle, SQL Server, etc).
📚
Analogia do "Arquivista Chefe"
Imagine o Banco de Dados como um GRANDE ARQUIVO em uma biblioteca. O SGBD é o "Arquivista Chefe". Você não pode simplesmente gritar ou fazer gestos - precisa usar um IDIOMA FORMAL para fazer perguntas e dar ordens. Esse idioma é o SQL!

Exemplos de "Conversas" com o Banco

🔍
SELECT
"Mostre-me todos os livros publicados em 2024"
➕
INSERT
"Adicione este novo livro ao catálogo"
✏️
UPDATE
"Atualize o preço deste livro"
🗑️
DELETE
"Remova este livro do catálogo"
IMPORTANTE: SQL não é case-sensitive (SELECT = select), mas POR CONVENÇÃO usamos COMANDOS EM MAIÚSCULO e nomes de tabelas/colunas em minúsculo para melhor legibilidade.

🔧 DDL vs. DML - Dois "Dialetos" do SQL

📐
DDL (Data Definition Language)

Nome: Linguagem de Definição de Dados

Função: Cria ou muda a ESTRUTURA das tabelas

Analogia: É como um arquiteto alterando a planta de uma biblioteca (mudando as prateleiras, criando novas seções)

Comandos principais:

  • ✓ CREATE TABLE - Cria uma nova tabela
  • ✓ DROP TABLE - Remove uma tabela
  • ✓ ALTER TABLE - Modifica a estrutura
  • ✓ CREATE INDEX - Cria um índice
Exemplo DDL: 
CREATE TABLE produtos (
    id INT PRIMARY KEY,
    nome VARCHAR(100),
    preco DECIMAL(10,2)
);
📊
DML (Data Manipulation Language)

Nome: Linguagem de Manipulação de Dados

Função: Manipula os DADOS dentro das estruturas

Analogia: É como um bibliotecário cadastrando/consultando/atualizando livros nas prateleiras existentes

Comandos principais:

  • ✓ SELECT - Consulta dados
  • ✓ INSERT - Adiciona novos dados
  • ✓ UPDATE - Atualiza dados existentes
  • ✓ DELETE - Remove dados
Exemplo DML: 
SELECT nome, preco
FROM produtos
WHERE preco > 100;

🔍 Comando SELECT - A Base das Consultas

O SELECT é o comando mais usado em SQL. Com ele, você CONSULTA (busca) dados no banco.

Estrutura Básica:
SELECT colunas
FROM tabela
WHERE condição
ORDER BY coluna;
Anatomia do SELECT - 4 Partes Principais
  1. SELECT - "O QUE você quer ver"

    Lista as colunas que você quer no resultado

    Exemplo: SELECT nome, preco

  2. FROM - "DE ONDE você quer buscar"

    Especifica a tabela de origem

    Exemplo: FROM produtos

  3. WHERE - "QUAIS linhas você quer filtrar"

    Define condições para filtrar registros

    Exemplo: WHERE preco > 500

    Opcional (se omitido, retorna todas as linhas)

  4. ORDER BY - "COMO você quer organizar"

    Ordena o resultado por uma ou mais colunas

    ASC = Ascendente (A-Z, 0-9) [padrão]

    DESC = Descendente (Z-A, 9-0)

    Exemplo: ORDER BY nome ASC

    Opcional

📝 Cláusula SELECT - O Que Você Quer Ver

Definição
A cláusula SELECT define QUAIS COLUNAS você quer visualizar no resultado.
Sintaxe:
SELECT coluna1, coluna2, coluna3
Exemplo 1 - Selecionar colunas específicas
SELECT nome, preco
FROM produtos;
Resultado: Retorna APENAS as colunas 'nome' e 'preco'
Exemplo 2 - Selecionar TODAS as colunas
SELECT *
FROM produtos;
Resultado: Retorna TODAS as colunas da tabela
IMPORTANTE: Evite usar * em produção! Especifique sempre as colunas necessárias.
Exemplo 3 - Selecionar com alias (apelido)
SELECT nome AS produto, preco AS valor
FROM produtos;
Resultado: As colunas aparecem com os nomes 'produto' e 'valor' no resultado

📂 Cláusula FROM - De Onde Buscar

Definição
A cláusula FROM especifica DE QUAL TABELA você quer buscar os dados.
Sintaxe:
SELECT colunas
FROM nome_da_tabela;
Exemplo:
SELECT nome, preco
FROM produtos;
Leitura: "Selecione nome e preço DA TABELA produtos"
⚠️ IMPORTANTE
  • O nome da tabela DEVE existir no banco de dados
  • Case-sensitive em alguns SGBDs (PostgreSQL)
  • Sempre verifique o nome correto da tabela antes de consultar

🎯 Cláusula WHERE - Filtrando Resultados

Definição
A cláusula WHERE define CONDIÇÕES para filtrar quais linhas você quer no resultado. Só aparecem as linhas que atendem à condição.
Sintaxe:
SELECT colunas
FROM tabela
WHERE condição;
Operadores Comuns no WHERE
  • = - Igual a
  • > - Maior que
  • < - Menor que
  • >= - Maior ou igual
  • <= - Menor ou igual
  • <> ou != - Diferente de
  • AND - E lógico (ambas condições devem ser verdadeiras)
  • OR - OU lógico (pelo menos uma condição deve ser verdadeira)
  • LIKE - Padrão de texto (usa % como coringa)
Exemplos Práticos:

Exemplo 1: Produtos com preço maior que 100

SELECT nome, preco
FROM produtos
WHERE preco > 100;

Exemplo 2: Produtos de uma categoria específica

SELECT nome, preco
FROM produtos
WHERE categoria = 'Eletrônicos';

Exemplo 3: Múltiplas condições com AND

SELECT nome, preco
FROM produtos
WHERE preco > 100 AND categoria = 'Eletrônicos';

📊 Cláusula ORDER BY - Ordenando Resultados

Definição
A cláusula ORDER BY ordena os resultados por uma ou mais colunas. Você pode ordenar de forma crescente (ASC) ou decrescente (DESC).
Sintaxe:
SELECT colunas
FROM tabela
ORDER BY coluna [ASC|DESC];
⬆️
ASC (Ascendente)
Ordem crescente: A-Z, 0-9
É o padrão (se não especificar)
⬇️
DESC (Descendente)
Ordem decrescente: Z-A, 9-0
Precisa especificar explicitamente
Exemplos:

Exemplo 1: Ordenar por nome (A-Z)

SELECT nome, preco
FROM produtos
ORDER BY nome ASC;

Exemplo 2: Ordenar por preço do maior para o menor

SELECT nome, preco
FROM produtos
ORDER BY preco DESC;

Exemplo 3: Ordenar por múltiplas colunas

SELECT nome, categoria, preco
FROM produtos
ORDER BY categoria ASC, preco DESC;

Ordena primeiro por categoria (A-Z), depois por preço (maior-menor) dentro de cada categoria

🎯 SELECT Completo - Juntando Tudo

Exemplo Completo com Todas as Cláusulas
SELECT nome, categoria, preco
FROM produtos
WHERE preco > 50 AND categoria = 'Eletrônicos'
ORDER BY preco DESC;
Leitura passo a passo:
  1. SELECT nome, categoria, preco
    → "Quero ver as colunas: nome, categoria e preço"
  2. FROM produtos
    → "Da tabela produtos"
  3. WHERE preco > 50 AND categoria = 'Eletrônicos'
    → "Mas APENAS os produtos que custam mais de 50 E são da categoria Eletrônicos"
  4. ORDER BY preco DESC
    → "E mostre os resultados ordenados por preço, do mais caro para o mais barato"
💡
Dica Importante
A ordem das cláusulas no SQL é FIXA:
  1. SELECT (obrigatório)
  2. FROM (obrigatório)
  3. WHERE (opcional)
  4. ORDER BY (opcional)

Não pode mudar esta ordem!

➕ Comando INSERT - Adicionando Dados

O INSERT é usado para ADICIONAR NOVOS REGISTROS (linhas) em uma tabela.

Estrutura Básica:
INSERT INTO nome_tabela (coluna1, coluna2, coluna3)
VALUES (valor1, valor2, valor3);
Anatomia do INSERT - 3 Partes
  1. INSERT INTO nome_tabela

    Especifica EM QUAL TABELA você quer inserir

  2. (coluna1, coluna2, coluna3)

    Lista as colunas que receberão valores

    Opcional se você vai preencher TODAS as colunas na ordem correta

  3. VALUES (valor1, valor2, valor3)

    Os valores que serão inseridos, na mesma ordem das colunas

    Textos devem estar entre aspas simples: 'texto'

    Números não precisam de aspas: 123

⚠️ IMPORTANTE: A ordem dos valores em VALUES deve corresponder EXATAMENTE à ordem das colunas especificadas!

📝 INSERT - Exemplos Práticos

Exemplo 1 - INSERT especificando colunas (RECOMENDADO)
INSERT INTO produtos (nome, categoria, preco)
VALUES ('Notebook', 'Eletrônicos', 2500.00);

Resultado: Adiciona um novo produto com os valores especificados

✓ Mais seguro - você controla quais colunas está preenchendo

Exemplo 2 - INSERT sem especificar colunas
INSERT INTO produtos
VALUES (1, 'Mouse', 'Eletrônicos', 45.00);

Atenção: Você DEVE fornecer valores para TODAS as colunas, na ordem exata da tabela

⚠️ Menos recomendado - se a estrutura da tabela mudar, o código quebra

Exemplo 3 - Inserir múltiplos registros de uma vez
INSERT INTO produtos (nome, categoria, preco)
VALUES 
    ('Teclado', 'Eletrônicos', 120.00),
    ('Monitor', 'Eletrônicos', 800.00),
    ('Webcam', 'Eletrônicos', 250.00);

Resultado: Insere 3 produtos de uma só vez

✓ Mais eficiente quando você precisa inserir vários registros

💡 Dica de Ouro

SEMPRE especifique as colunas no INSERT!

Isso torna seu código mais legível, seguro e resistente a mudanças na estrutura da tabela.

✨ Boas Práticas em SQL

📜
1. Formatação e Legibilidade
  • ✓ Use MAIÚSCULAS para palavras-chave SQL (SELECT, FROM, WHERE)
  • ✓ Use minúsculas para nomes de tabelas e colunas
  • ✓ Quebre comandos longos em múltiplas linhas
  • ✓ Indente adequadamente para facilitar leitura
🎯
2. Performance
  • ✓ Evite SELECT * - especifique apenas as colunas necessárias
  • ✓ Use WHERE para filtrar dados e reduzir resultados
  • ✓ Crie índices em colunas frequentemente usadas no WHERE
🔒
3. Segurança
  • ✓ Sempre valide dados de entrada antes de INSERT/UPDATE
  • ✓ Use prepared statements para evitar SQL Injection
  • ✓ Faça backup antes de executar DELETE ou UPDATE em massa
📊
4. Manutenibilidade
  • ✓ Dê nomes descritivos para tabelas e colunas
  • ✓ Sempre especifique colunas no INSERT INTO
  • ✓ Comente queries complexas para explicar a lógica
  • ✓ Teste suas queries em ambiente de desenvolvimento primeiro
