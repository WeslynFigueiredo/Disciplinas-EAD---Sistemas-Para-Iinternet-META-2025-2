## 📚 Estrutura das Disciplinas


| Disciplina | Conteúdo Principal
| :--- | :--- |
| **🖥️ Arquitetura e Organização de Computadores (AOC)** | Base de hardware: Sistemas Numéricos, Memória, CPU e ISA.
| **💾 Banco de Dados I (BD I)** | Modelagem (MER), Normalização e Fundamentos de SQL (DML). |
| **📈 Negócios e Marketing Eletrônico (NME)** | Estratégia Digital, Persona, Funil de Vendas, KPIs (ROI, CAC).
| **📐 Arquitetura e Padrões de Software (APS)** | Estilos Arquiteturais, Padrões GoF (Criacionais, Estruturais), SOLID e Dívida Técnica.
