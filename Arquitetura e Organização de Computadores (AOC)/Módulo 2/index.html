🔧 O Desafio Fundamental

Como representar números NEGATIVOS usando apenas 0s e 1s?

Objetivo Maior:

Permitir que o computador faça SUBTRAÇÕES usando apenas circuitos de ADIÇÃO

8 - 3 = 8 + (-3)

Transformar subtração em adição!

💡 Por Que Isso Importa?

⚡

Simplicidade de Hardware

Circuitos de soma são muito mais simples que circuitos de subtração

🔌

Um Único Circuito

Um único circuito somador resolve tudo: positivos, negativos e zeros

🚀

Performance e Custo

Menos transistores = computadores mais rápidos, menores e baratos

📊 Método Sinal-Magnitude

Como Funciona?

+25 em 8 bits:

00011001

0 = positivo | 0011001 = magnitude

-25 em 8 bits:

10011001

1 = negativo | 0011001 = magnitude

⚠️ Limitação 1: Duplo Zero

Existem DUAS representações para zero!

+0 (8 bits):

00000000

-0 (8 bits):

10000000

✗ Desperdício de uma combinação binária valiosa

✗ Circuitos precisam de tratamento especial para comparações

⚠️ Limitação 2: Complexidade Aritmética

Para cada soma ou subtração, o circuito precisa:

1️⃣ Verificar

Os sinais de ambos os números

2️⃣ Decidir

Se vai somar ou subtrair

3️⃣ Determinar

O sinal do resultado

4️⃣ Ajustar

Se houver overflow

Resultado: Circuitos complexos, lentos e caros ❌

🔄 Complemento de Um (Introdução)

Definição: Um passo intermediário para o Complemento de Dois

Processo em 2 Passos:

1

Escreva o número POSITIVO em binário

2

INVERTA todos os bits (0 vira 1, 1 vira 0)

Exemplo: Complemento de Um de 10

Positivo

00001010

Complemento de 1

11110101

⚠️ Complemento de Um: Ainda tem Duplo Zero!

O problema persiste:

+0

00000000

-0

11111111

Por isso, o Complemento de Um NÃO é usado sozinho 🚫

É apenas um PASSO INTERMEDIÁRIO para o Complemento de Dois ⬇️

✨ Complemento de Dois: O Padrão Universal

✓

Zero Único

Existe apenas UMA representação para zero

✓

Aritmética Simples

Soma e subtração usam as MESMAS regras

✓

Hardware Eficiente

Um único circuito somador resolve TUDO

✓

Detecção Automática

MSB = 1 significa negativo, MSB = 0 significa positivo

🔧 Complemento de Dois: Algoritmo em 3 Passos

PASSO 1

Binário do Positivo

Converta N (sem sinal) para binário

⬇️
PASSO 2

Complemento de Um

Inverta todos os bits (0↔1)

⬇️
PASSO 3

Adicione 1

Some 1 ao resultado do Passo 2

📝 Exemplo: Representar -10 em C2 (8 bits)

PASSO 1: Binário de +10

00001010

PASSO 2: Complemento de Um

11110101

PASSO 3: Adicionar 1

  11110101
+ 00000001
  ────────
  11110110

✓ RESULTADO:

-10₁₀ = 11110110₂

✅ Verificação: -10 + 10 = 0

Se a representação está correta, então (-10) + (+10) = 0

  11110110  (-10 em C2)
+ 00001010  (+10 em binário)
  ────────
 100000000  (9 bits)

Observação Crítica:

Em sistemas de 8 bits, o bit extra (carry out) é descartado automaticamente

Resultado final: 00000000 = 0₁₀ ✓

📝 Exemplo: Representar -127 em C2 (8 bits)

PASSO 1: Binário de +127

01111111

(maior número positivo em 8 bits)

PASSO 2: Complemento de Um

10000000

PASSO 3: Adicionar 1

  10000000
+ 00000001
  ────────
  10000001

✓ RESULTADO:

-127₁₀ = 10000001₂

🔄 Exemplo: Converter 10000001₂ para Decimal

PASSO 1: Verificar o MSB

Binário: 10000001

MSB = 1 → Número é NEGATIVO

PASSO 2: Inverter Bits + Adicionar 1

Original:      10000001
Inverter:      01111110
Adicionar 1: + 00000001
          ────────
Resultado:     01111111

PASSO 3: Converter para Decimal

01111111₂ = 127₁₀

✓ RESULTADO:

10000001₂ = -127₁₀

📊 Intervalos de Representação

Fórmulas Fundamentais para N bits:

Mínimo: -2N-1

Máximo: 2N-1 - 1

Exemplos Práticos:

4 Bits

-23 a 23 - 1

-8 a +7

8 Bits

-27 a 27 - 1

-128 a +127

16 Bits

-215 a 215 - 1

-32.768 a +32.767

32 Bits

-231 a 231 - 1

-2.147.483.648 a +2.147.483.647

⚡ Mais Dicas: Erros Comuns

❌

Confundir C1 com C2

Complemento de Um NÃO é o final! Você PRECISA somar 1 ao C1

❌

Esquecer o Sinal

Sempre coloque o sinal negativo na resposta final

❌

Ignorar o Intervalo

Cuidado com overflow! -128 é o limite mínimo para 8 bits

❌

Não Verificar

Sempre faça a verificação somando com o oposto!

📝 Resumo Executivo

  • ✓ Necessidade: Transformar subtrações em adições usando apenas circuitos somadores
  • ✓ Sinal-Magnitude: Simples mas com 2 zeros e circuitos complexos ❌
  • ✓ Complemento de Um: Passo intermediário que inverte todos os bits
  • ✓ Complemento de Dois: Método universal = C1 + 1 ✓
  • ✓ Intervalo (N bits): Mínimo = -2^(N-1) | Máximo = 2^(N-1) - 1
  • ✓ Verificação: Sempre some número com seu oposto para confirmar (deve dar 0)
