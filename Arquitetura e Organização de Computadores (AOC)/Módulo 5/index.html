📖 O que é ISA?

ISA = Instruction Set Architecture

ISA é a INTERFACE entre o SOFTWARE (programas) e o HARDWARE (processador)

Define TODO o conjunto de comandos que uma CPU específica pode executar

🎯 ISA = Contrato entre Software e Hardware

O programador escreve instruções → A CPU deve saber executá-las!

Cada processador tem sua própria ISA (x86, ARM, MIPS, RISC-V...)

📚 Analogia: ISA = Dicionário de Comandos

🤖 "Idioma" do Processador (ISA)

A CPU tem um dicionário de instruções (ADD, SUB, LOAD...) que ela consegue executar

Se você enviar uma instrução que NÃO está na ISA, a CPU não saberá o que fazer! ❌

✓ ISA = Todas as "palavras" (instruções) que o processador compreende!

🔢 Os 4 Tipos Básicos de Instruções

1️⃣ TRANSFERÊNCIA

Move Dados Entre Lugares

Registradores ↔ Memória | Registrador ↔ Registrador

2️⃣ ARITMÉTICA

Operações Matemáticas

Soma, Subtração, Multiplicação, Divisão

3️⃣ LÓGICA

Operações Booleanas e de Bits

AND, OR, NOT, XOR, Shift (deslocamento)

4️⃣ CONTROLE (Branch)

Altera o Fluxo de Execução

JUMP, BRANCH, CALL - Muda o Program Counter (PC)

📦 Tipo 1: Instruções de Transferência de Dados

O que fazem?

Movem dados de um lugar para outro SEM MODIFICÁ-LOS

Exemplos Práticos:

LOAD R1, [1000]

Carrega o valor do endereço de memória 1000 no registrador R1

STORE R2, [2000]

Armazena o valor do registrador R2 no endereço de memória 2000

MOV R3, R4

Copia o valor de R4 para R3

🎯 Função: Transportar dados entre registradores e memória!

➕ Tipo 2: Instruções Aritméticas

O que fazem?

Realizam operações matemáticas (calculadora da CPU!)

Exemplos Práticos:

ADD R1, R2, R3

R1 = R2 + R3 (soma os valores de R2 e R3, coloca resultado em R1)

SUB R4, R5, R6

R4 = R5 - R6 (subtração)

MUL R7, R8, R9

R7 = R8 × R9 (multiplicação)

DIV R10, R11, R12

R10 = R11 ÷ R12 (divisão)

🔀 Tipo 3: Instruções Lógicas

O que fazem?

Realizam operações booleanas bit a bit (manipulam 0s e 1s)

Exemplos Práticos:

AND R1, R2, R3

R1 = R2 AND R3 (E lógico bit a bit)

Exemplo: 1010 AND 1100 = 1000

OR R4, R5, R6

R4 = R5 OR R6 (OU lógico)

Exemplo: 1010 OR 1100 = 1110

NOT R7, R8

R7 = NOT R8 (inverte todos os bits)

Exemplo: NOT 1010 = 0101

SHL R9, R10, 2

R9 = R10 deslocado 2 bits à esquerda (shift left = multiplica por 4)

🔄 Tipo 4: Instruções de Controle (Branch)

O que fazem?

Alteram o FLUXO DE EXECUÇÃO do programa mudando o Program Counter (PC)

Permitem loops, condicionais (if/else) e chamadas de funções

Exemplos Práticos:

JUMP [endereço]

Pula incondicionalmente para o endereço especificado (muda PC)

BEQ R1, R2, [label]

Branch if Equal: Se R1 == R2, pula para o label

BNE R3, R4, [label]

Branch if Not Equal: Se R3 ≠ R4, pula para o label

CALL [função]

Chama uma função (salva PC e pula para função)

💻 Linguagem de Montagem (Assembly)

O que é Assembly?

Assembly = Linguagem de BAIXO NÍVEL que usa mnemônicos para representar instruções da ISA

Cada instrução Assembly se traduz QUASE DIRETAMENTE em código de máquina (binário)

Por que Mnemônicos?

Porque é IMPOSSÍVEL lembrar números binários!

Ao invés de 10110001011001010110

Escrevemos ADD R1, R2, R3

Muito mais fácil de entender e escrever! ✓

🔄 Assembly vs Código de Máquina

📝 ASSEMBLY

Linguagem legível para humanos

ADD R1, R2, R3
LOAD R4, [100]
STORE R5, [200]
JUMP [300]

✓ Fácil de ler e escrever!

🔢 CÓDIGO DE MÁQUINA

Binário que a CPU executa

10110001011001010110
11001010111001100101
01110011001110101100
00110101100111001011

❌ Impossível de ler!

🎯 Assembly é traduzido para Código de Máquina pelo MONTADOR (Assembler)!

🔧 O Montador (Assembler)

O que é o Montador?

Montador = Programa que traduz código ASSEMBLY em CÓDIGO DE MÁQUINA (binário)

Como funciona?

1

Lê o código Assembly

Arquivo .asm com mnemônicos

⬇️
2

Traduz para binário

Converte mnemônicos em opcodes binários

⬇️
3

Gera arquivo objeto

Arquivo .o ou .obj com código de máquina

🔗 O Ligador (Linker)

O que é o Ligador?

Ligador = Programa que COMBINA vários arquivos objeto em um ÚNICO EXECUTÁVEL

Por que precisamos dele?

Porque programas grandes são divididos em MÚLTIPLOS ARQUIVOS:

  • Seu código (main.o)
  • Bibliotecas (printf, scanf...)
  • Outros módulos (funções auxiliares)

🎯 Ligador junta tudo em um único arquivo .exe (Windows) ou .out (Linux)!

📊 Fluxograma: Do Código à Execução

Processo completo de compilação/montagem:

📝 CÓDIGO FONTE

programa.asm (Assembly) ou programa.c (C)

⬇️

🔧 COMPILADOR / MONTADOR

Traduz para código de máquina

⬇️

📦 CÓDIGO OBJETO

programa.o ou programa.obj (binário parcial)

⬇️

🔗 LIGADOR (LINKER)

Combina todos os arquivos objeto + bibliotecas

⬇️

✓ EXECUTÁVEL

programa.exe (Windows) ou a.out (Linux) - PRONTO PARA RODAR!

📚 Exemplo Completo: Programa Assembly

Programa que soma 5 + 3 e salva o resultado:

; Programa: Soma de dois números

LOAD R1, #5      ; Carrega 5 no registrador R1
LOAD R2, #3      ; Carrega 3 no registrador R2
ADD R3, R1, R2  ; R3 = R1 + R2 (3 = 5 + 3)
STORE R3, [100] ; Salva resultado no endereço 100
HALT            ; Para a execução

Análise Linha por Linha:

LOAD R1, #5 → Transferência (coloca 5 em R1)

ADD R3, R1, R2 → Aritmética (soma R1+R2)

STORE R3, [100] → Transferência (salva na memória)

💡 Por Que ISA é Importante?

🔌

Compatibilidade

Programas compilados para x86 rodam em qualquer CPU x86

⚙️

Abstração

Programadores não precisam saber detalhes internos da CPU

🔄

Portabilidade

Mesmo código pode rodar em diferentes implementações da mesma ISA

🚀

Otimização

Compiladores conhecendo a ISA geram código eficiente

🌐 ISAs Populares no Mundo Real

x86 / x86-64 (Intel, AMD)

PCs, laptops, servidores. ISA CISC (Complex Instruction Set)

ARM (Apple M1/M2, Qualcomm)

Smartphones, tablets, MacBooks. ISA RISC (Reduced Instruction Set)

RISC-V (Open Source)

ISA aberta e gratuita. Usada em pesquisa e IoT

MIPS

Roteadores, sistemas embarcados. ISA RISC clássica
